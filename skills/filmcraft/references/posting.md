# Write for the destination

Read the finished cut and the creator’s audience. Prepare copy only for requested outlets. Keep upload instructions separate from the public copy. Verify current platform limits, link placement, labels and music rights at release time. Check any DM offer can actually be fulfilled. Translation is its own writing pass.

| Outlet | Deliver | Example for the folded booklet |
| --- | --- | --- |
| YouTube | Searchable title, first two description lines, next action and an optional comment | **Why page 16 prints beside page 1.** Fold the outside sheet of a booklet and the strange order makes sense. Try the same puzzle with eight pages. |
| TikTok | Conversational first line, cover line and a useful question | “The printer put 16 next to 1. Before you fix it, fold it.” Cover: “Printer error?” |
| Instagram | A visual premise, compact caption and a deliverable CTA if requested | “These two numbers are on the same sheet. One ends up on the cover; the other goes around the back. Save this for your next zine.” |
| Bilibili | Native-language title, Chinese description, source or project credit and a subtitle track when available | 标题：为什么小册子的第 16 页和第 1 页印在一起？ 简介：把最外层的纸对折，再翻到背面。你就能看出印刷时的页序和阅读时有什么不同。 |
| X | Attach the clip and make one observation worth repeating; include a source link for a factual demonstration | “Open a stapled booklet flat. The front and back covers were neighbors long before the first reader turned a page.” |
| LinkedIn | A professional decision, its practical consequence and one informed question | “A designer sent me a file in reading order. The print proof put 16 beside 1. Folding a dummy tells you which order you’re checking. What do you check on paper before approving a job?” Use first person only when the creator actually had that experience. |

For a long documentary, use a specific title and an honest synopsis, credits, language and accessibility details, sources/rights links and chapter timestamps measured from the export. A teaser should resolve its own promise. Place any offer at the end of the platform variant that actually contains it.
